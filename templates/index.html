Educational Learning Modules

Core concepts in Computer Networks (CSE Curriculum, OSI Model, and Graph Theory).

1. Host / Workstation (End System) ▼
A computer or workstation functions as an end-system device that originates and terminates network communication traffic. In the TCP/IP model, hosts execute application protocols (HTTP, DNS, FTP) and manage transport sockets (TCP/UDP).
2. Network Switch (Layer 2) ▼
A switch is a Layer 2 (Data Link layer) multiport bridge that forwards Ethernet frames based on hardware MAC addresses stored in its Forwarding Information Base (FIB / MAC Address Table). Each switch port constitutes an isolated collision domain, significantly increasing network throughput.
3. Router (Layer 3 Gateway) ▼
A router operates at Layer 3 (Network layer) of the OSI model. Routers inspect destination IP addresses and make packet-forwarding decisions across disparate subnets and Wide Area Networks (WANs). Routers terminate broadcast domains and enforce network segmentation.
4. Physical vs Logical Topology ▼
Physical Topology refers to the tangible geometric layout and physical cabling connecting devices.

Logical Topology defines how data frames or packets actually travel across the physical medium (e.g., Ethernet IEEE 802.3 broadcast logic).
5. Graph Algorithms: BFS & Routing ▼
Network topologies are modeled mathematically as undirected graphs \(G = (V, E)\) where \(V\) represents devices and \(E\) represents physical links.

Breadth-First Search (BFS) systematically explores nodes in order of hop distance, producing the minimum-hop path in an unweighted graph in \(O(V + E)\) time. In real networks, protocols like RIP use hop count, while OSPF uses Dijkstra's weighted shortest path.
6. Educational Modeling Disclaimer ▼
Academic Notice: NetSim is an educational graph-theoretical simulator for topology structure, connectivity, and shortest-path visualization. It does not emulate physical Ethernet collision physics, real-time packet queueing, or hardware bit transmission.

About NetSim – Educational Network Topology Simulator

NetSim is a full-stack educational web application designed for Computer Science & Engineering students to master computer network topologies, graph theoretical models, and connectivity analysis.

Keyboard Shortcuts

  • Delete / Backspace: Delete selected device or connection
  • Ctrl + Z: Undo previous action
  • Ctrl + Y: Redo previous action
  • Escape: Clear selection or cancel link connection mode
  • Mouse Wheel: Smooth canvas zoom in / out

System Architecture

• Frontend: Modern HTML5, Responsive CSS3, Vanilla ES6+ JavaScript, Dynamic SVG visualization.
• Backend: Python 3 Flask REST API with graph theory modules.
• Database: SQLite with parameterized queries for persistent topology management.
